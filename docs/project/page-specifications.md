## Booking Request

Use a multi-step inquiry form:

1. Selected tour or custom tour
2. Dates and flexibility
3. Duration
4. Destinations
5. Interests
6. Group size
7. Accommodation level
8. Transportation preferences
9. Notes
10. Name
11. Email
12. Phone/WhatsApp
13. Country
14. Preferred contact method
15. Review
16. Privacy consent
17. Submit

Clearly state that submission does not reserve a seat and the agency will review it and send a quotation.
