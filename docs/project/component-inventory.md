## React Bits policy

Appropriate:

- One restrained hero text reveal
- One subtle premium background
- Limited editorial scroll reveals
- Gallery interaction

Not appropriate:

- Navbar behavior
- Mobile drawer
- Primary forms
- Standard buttons
- Every section on a page
